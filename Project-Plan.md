# Project Plan

## Project Title

**Streamlining IT Procurement**

## 1. Project Overview

**Streamlining IT Procurement** is a ServiceNow-based project designed to simplify and improve the IT procurement process within an organization.

The project helps employees request IT products or services, enables the procurement team to review and process requests, and provides better visibility into the procurement workflow.

The system aims to reduce manual work, improve request tracking, and make the IT procurement process more organized and efficient.

## 2. Project Objectives

* To simplify the IT procurement request process.
* To provide a centralized system for managing IT procurement requests.
* To reduce manual processing and paperwork.
* To improve communication between employees, IT teams, and procurement teams.
* To track procurement requests from submission to completion.
* To improve transparency and visibility of request status.
* To maintain procurement-related records in a structured manner.

## 3. Main Modules

### IT Procurement Request

Employees can submit requests for required IT products, hardware, software, or services.

### Request Management

Procurement and IT teams can view, review, and manage submitted requests.

### Approval Process

Requests can be reviewed and approved by the appropriate personnel before procurement.

### Request Tracking

Users can track the status and progress of their procurement requests.

### Procurement Processing

Approved requests can be processed by the procurement team according to organizational requirements.

### Notifications

Users and responsible teams can receive updates regarding request status and actions.

### Reporting

The system can provide useful information about procurement requests and their current status.

## 5. Project Workflow

The basic procurement workflow is:

**Employee Request → Request Review → Approval → Procurement Processing → Order/Delivery → Request Completion**

## 6. Procurement Process

1. Employee identifies an IT requirement.
2. Employee submits an IT procurement request.
3. The request is recorded in the ServiceNow system.
4. The responsible team reviews the request.
5. Approval is obtained when required.
6. The procurement team processes the approved request.
7. The requested product or service is arranged.
8. The request status is updated.
9. The request is completed and closed.

* Request status tracking.
* Automated notifications.
* Centralized procurement information.
* Reports for monitoring procurement activities.

## 10. Expected Project Outcome

The **Streamlining IT Procurement** project will provide a structured and centralized approach to managing IT procurement activities. It will help organizations manage requests, approvals, processing, tracking, and reporting through a single ServiceNow-based platform.
