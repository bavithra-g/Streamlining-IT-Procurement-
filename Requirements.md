# Requirements

## 1. Project Title

Streamlining IT Procurement

## 2. Project Description

The project aims to automate the procurement process for standard laptop orders.
It provides a structured workflow for submitting, validating, approving, and
processing laptop requests through the ServiceNow platform.

## 3. Functional Requirements

### 3.1 Laptop Request Creation

- Users should be able to submit a laptop request.
- The request should contain required user and laptop details.
- The system should validate the entered information.

### 3.2 Standard Laptop Selection

- Users should be able to select a standard laptop model.
- The system should provide predefined laptop options.
- Only approved standard laptop configurations should be available.

### 3.3 Request Validation

- The system should validate mandatory fields.
- Invalid or incomplete requests should not be submitted.
- Appropriate messages should be displayed when validation fails.

### 3.4 Approval Process

- Submitted requests should be routed through the required approval process.
- Approvers should be able to approve or reject requests.
- The request status should be updated based on the approval decision.

### 3.5 Automated Processing

- Approved laptop requests should be processed automatically.
- The system should reduce manual procurement activities.
- Request information should be maintained throughout the workflow.

### 3.6 Request Tracking

- Users should be able to track the status of their laptop request.
- The system should maintain request history.
- Status changes should be recorded for reference.

## 4. Non-Functional Requirements

### 4.1 Usability

- The application should have a simple and user-friendly interface.
- Forms should be easy to understand and complete.

### 4.2 Performance

- Requests should be processed within a reasonable time.
- The system should respond efficiently to user actions.

### 4.3 Security

- Only authorized users should be able to access procurement functions.
- User and request information should be protected.

### 4.4 Reliability

- The system should maintain accurate request information.
- Workflow processing should work consistently without data loss.

### 4.5 Maintainability

- The application should be easy to maintain and update.
- Business rules, client scripts, and UI policies should be organized properly.

## 5. ServiceNow Requirements

The project uses the following ServiceNow features:

- Service Catalog
- Catalog Items
- Client Scripts
- UI Policies
- Business Rules
- Workflows / Flow Designer
- Approvals
- Notifications
- Tables and Records

## 6. Expected Outcome

The system should provide an automated and organized process for standard
laptop procurement, reducing manual work and improving request tracking,
validation, approval, and processing.
